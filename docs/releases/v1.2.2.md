# Git Agent Clear v1.2.2

本次更新将产品名称正式统一为 **Git Agent Clear**，并补齐公开仓库的安装、使用和发布说明。

## 更新内容

- 主窗口、页头、关于页面、中英文提示、独立 Diff/Merge 工具统一显示 Git Agent Clear。
- macOS 应用显示名、Windows 安装向导及程序属性、Linux 应用名称与打包默认值统一。
- 保留现有 Clear 应用标识、配置目录和钥匙串服务名，升级后继续使用已有设置。
- 补全 README 首次使用步骤，解释个人远程仓库、可选 AI 的用途、文件时间追溯的边界，以及功能接入和真实账号验收的区别。
- Linux 安装包补充对系统 Git 的依赖声明。
- 发布页提供中文说明及 SHA-256 校验文件；保留 v1.2.1 历史版本。

## 下载与安装

- macOS：`GitAgent-Clear-1.2.2-macOS.dmg`，Universal（Apple Silicon / Intel），应用声明最低 macOS 11。
- Windows x64：`GitAgent-ClearSetup-1.2.2.exe`。
- Debian / Ubuntu x86_64：`GitAgent-Clear_1.2.2_amd64.deb`。
- `SHA256SUMS.txt` 包含以上三个文件的校验值。

先安装系统 Git，再安装本应用。macOS 安装包采用临时签名，未做 Apple Developer ID 签名和公证。请确认下载来源后按系统提示允许打开。

正式版本启用了本仓库的更新源；本地默认开发构建不会启用自更新。也可直接下载安装新版本。退出旧应用后安装并重新打开，可看到统一后的名称。

## 验证范围

名称统一代码已通过本机回归：675 项通过、0 失败、3 项外部 AI 测试按设计忽略。本版本需通过 GitHub Actions 的三个平台测试及打包后才发布；构建记录可在仓库 Actions 页面查看。
