# Git Agent Clear v1.2.1

这是 2026-09-20 在独立仓库发布的历史版本。标签及三个平台安装包保留原样。

本版本包含引导式 Git 工作台、文件时间追溯，以及四项使用体验改进：危险操作分区、历史空状态引导、分支高级说明折叠、临时收起操作文案统一。更新源指向 `awiggy/git-clear-desktop`。

该版本安装后的应用名为 Git Agent Clear，但部分窗口和界面仍显示 Git Agent。名称统一改动从 v1.2.2 正式安装包起提供。

## 安装包

- macOS Universal：`GitAgent-Clear-1.2.1-macOS.dmg`
- Windows x64：`GitAgent-ClearSetup-1.2.1.exe`
- Debian / Ubuntu x86_64：`GitAgent-Clear_1.2.1_amd64.deb`

使用前需要安装系统 Git。macOS 包采用临时签名，未做 Apple Developer ID 签名和公证。历史构建的三平台测试及打包均已通过；真实外部账号/API 场景的待验收项见项目验收清单。
